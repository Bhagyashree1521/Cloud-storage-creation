# DESCRIPTION OF THE TASK AND PICTURES OF THE OUTPUT

As per my first task, I have created a google cloud storage and also added example files to my bucked.
First I create a new project to organize cloud resources. Then I enable the "Cloud Storage" API.
After this I clicked on “Storage” then “Buckets” in the menu and then *“Create”.  
After this I entered a *unique name* for my bucket of my choice.  
Then I selected *location type* as multi-region for my cloud bucket.  
Then I was asked to Select a *storage class* which i set to standard.  
I Configured *access control* as Uniform.  
At the end I Clicked *“Create” and thus my bucket was created successfully.
And to upload example files I clicked on upload files or folders and thus my flies were uploaded to my newly created bucket successfully.
